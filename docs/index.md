# Вики по 1С

Личная база знаний по **1С:Предприятие**: язык, конфигурации, администрирование, интеграции и практические рецепты.

## Разделы

- [Основы](basics/index.md) — платформа, режимы работы, базовые понятия
- [Язык 1С](language/index.md) — синтаксис, типы, приёмы программирования
- [Конфигурации](configuration/index.md) — объекты метаданных, типовые конфигурации
- [Администрирование](admin/index.md) — обслуживание баз, пользователи, резервные копии
- [Интеграции](integration/index.md) — обмен данными, HTTP, OData, внешние системы
- [Рецепты](recipes/index.md) — короткие решения типовых задач

## Как пополнять

Статьи пишутся в Markdown в каталоге `docs/`, по шаблону `templates/article-template.md`. После `git push` сайт обновляется автоматически.
